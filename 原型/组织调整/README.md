
## 页面与业务入口

| 页面 | 作用 |
| --- | --- |
| index.html | 方案列表、筛选、新增方案弹框、演示数据重置 |
| 02-新建方案.html | 新增方案直达兼容页；正常入口为列表弹框 |
| 03-工作台.html | 组织／编制／人员三栏；组织范围驱动、独立人编分组与搜索、多选、组织拖拽、职位管理、范围补充、Undo／Redo；前后对比和提交弹框 |

| 06-演示自测.html | 内部数据层自测和故障注入；非业务页面 |

工作台顶部“编辑方案信息”可修改方案名称、调整层级、调整原因和详细原因；生效日期只读；调整范围在同一弹框中维护，显式根无有效影响时可移除。名称点击展示详情占位提示；编制编码可查看本轮占用、预留与期限详情；组织从操作菜单编辑，职位从“管理职位”维护，管理入口也提供于人编表单。组织可拖拽排序，职位在管理弹框用把手及插入线排序。完整字段见 PRD F-02—F-06。

编制面板按 PRD §0.8 精简：标题后显示非零统计，职位仅显示总编／可用空编。行内按编码、两胶囊标签位、信息和操作对齐；胶囊同行。窗口小于 1280 CSS px 时，信息与操作放到第二行，操作右对齐；职位标题及统计可换行，全选／增编另行靠右。浮动人数气泡显示姓名和期限；可用编制行尾统一“操作 ▾”，菜单依次为绑定员工、绑定兼职、分隔线、调编、复制、减编；复制仍支持数量。主职／兼职／浮动占用行提供属性调编（部门及职位锁定）、属性复制和解除绑定／停止兼职／整批取消浮动；取消浮动后成为普通空编，人员转待绑编。招聘需求／Offer、姓名为详情占位。

人员标题为主职／长期兼职／短期兼职，主职始终显示，长期／短期为 0 时隐藏对应项及分隔符，在所选部门直属范围按主职优先、长期其次、短期最后去重。兼职行不显示调岗，主职行调岗保留；未来安排直接放在职位明细中，当前人员未来调出／离职通过当前行未来胶囊查看。未来审批中调入不锁编；未来事项不参与当前人员多选。状态原因点击查看，短期截止日期留在表单和详情。

两栏选择互斥，编制全选仅选择可用空编。自动匹配在当前组织各直属职位内处理应占编未绑定任职，排除不占编和异常空编；待绑定与异常阻止提交。共享职位等高与滚动、基准减编原位恢复、新增净零和撤销／重做沿用；恢复不恢复人员绑定。浮动逐人解除仍保留其余占用，取消浮动则整批释放。

### 调岗自动占编

人员可拖到组织、两栏职位标题或可用空编，沿用调岗表单确认；组织落点先选职位，所有入口只自动分配最终职位的合法空编。普通带编保留原绑定，不匹配仍移动并提示异常；浮动人员只释放本人原绑定，不携带原浮动名额。未分配到的应占编人员先移动、标待绑编，提交前必须解决。具体空编落点不带原编；同职位浮动／未绑定应占编人员仅绑定。表单可查看逐人分配，支持整批撤销。

组件映射：沿用 Modal、DeptTreeSelect、职位 Select、EmployeeSelect；编制安排使用现有提示样式和折叠明细。需求评估通过，主流程及分配顺序已确认；正式应占编来源等既有接入边界不变。

### 组织停用与取消新增

本方案新增／复制组织统一“取消新增”，既有组织才叫“停用”。无关联简单确认后直接移除；有关联复用整体转移／先取消后处理表单，人编不提前删除，未来／预留继续阻断直接取消。保留的取消节点显示“已取消新增”，有未解决引用时叠加待处理；既有组织／职位须先转出，新增安全空对象在提交时清理，预览只读，退回恢复。停用／取消节点仅保留启用／恢复新增及管理职位，隐藏新增与复制；顶部新增组织入口保留。支持撤销／重做，取消不复用临时序号。

仅有当前主职／兼职时可选择“先停用，后续处理人员”；子树组织停用，职位状态和可用名额在草稿中保留，当前任职及绑定保留并显示待处理。人员可调出（含普通带编、浮动本人释放），兼职可停止，源名额释放后保留到提交收尾，提交时自动停用残留职位并关闭安全空编，全部处理前不可提交。未来人员、未来调入目标引用及招聘预留继续阻断，不新增单据处理入口。

可从管理职位“编辑 → 所属组织”或多选“转移”整体安置职位，未来人员、Offer、招聘预留和编制随稳定引用跟随，日期和审批不变。来源组织停用但职位自身有效时仍可编辑转出；目标须有效且在方案范围内。提交预览包含自动收尾数量和结果，取消不写草稿；审批退回恢复当次自动关闭的对象。启用组织不会恢复主动停用／减编或迁走的对象；旧草稿历史关闭对象不自动重建。

### 职位及统一操作

组织、可用／占用编制、管理职位的单项入口均为“操作 ▾”，菜单按对象与状态变化，多选条继续平铺；预留只读，已减编仍直接恢复。新增／复制职位单项用“取消新增”，有当前或历史引用时先处理。停用组织下自身有效职位仍可编辑、转出或复制到有效目标；目标检查完整祖先有效性。

管理职位有效多选为转移／复制／停用／取消选择，停用多选为启用／取消选择，两类分开。批量停用中新增职位按取消新增处理；失败整批回滚。批量解除绑定仅释放主职编制，保留兼职关系及浮动其他人。
