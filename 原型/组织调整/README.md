# 组织调整 Demo 交付说明

当前规格：`../../PRD.md` V0.29；技术实现：`../../TECH.md` V0.29；历史决策：`../../DISSCUSION.md`，最新见一百一十六—一百三十一节。本文只说明运行、入口、验证和接入边界，字段规则以 PRD 为准。

## 运行与预览

Vue 3 + Ant Design Vue 4 + dayjs，使用本地 vendor；浏览器无需构建或后端。Node 仅用于测试。

```bash
python3 <skill-root>/scripts/serve.py --dir "原型/组织调整" --page "index.html" --port <本工作树端口>
```

通过输出的 HTTP 地址预览，不使用 file://。不同工作树使用不同端口，避免 localStorage 相互影响。Git 提交、main 合并及 GitHub Pages 发布流程见 TECH §7.1；发布内容从已提交 main 的本目录平铺到 gh-pages 根目录，排除本 README。

## 页面与业务入口

| 页面 | 作用 |
| --- | --- |
| index.html | 方案列表、筛选、新建方案弹框、演示数据重置 |
| 02-新建方案.html | 新建方案直达兼容页；正常入口为列表弹框 |
| 03-工作台.html | 组织／职位／人员与编制三栏；四类表单、拖拽、范围补充、Undo／Redo；前后对比和提交弹框 |
| 04-前后对比.html | 工作台嵌入的对比／提交确认页，保留直达兼容入口 |
| 05-方案详情.html | 审批、版本与附件占位、生效结果、演示状态流转 |
| 06-演示自测.html | 内部数据层自测和故障注入；非业务页面 |

工作台顶部“编辑方案信息”可修改方案名称、调整层级、调整原因和详细原因；生效日期只读；调整范围在同一弹框中维护，显式根无有效影响时可移除。工作台名称／编制编码点击只弹出新标签页详情占位提示，不实际导航；组织和职位编辑从“操作”菜单进入。完整字段及默认值见 PRD F-02—F-06；复制范围用四种 Radio，同级排序只通过拖拽。编制变更默认原部门和职位，允许仅改属性；恢复减编为可用名额，不恢复人编绑定。

## 演示数据与兼容

- 案例一 `plan-case1`：范围内 9 职位、24 在职员工、28 编制、4 可用空编。
- 案例二 `plan-case2`：范围内 8 职位、18 在职员工、3 未来人员、26 编制、4 可用空编；有需求预留和停用阻断案例。
- `scopeDemo`：独立的范围／时间轴／在途编制流程校验数据，不进入预置方案列表。
- 华东数据：只供第 13 章数据自测使用。
- 当前 schema v11；兼容 v7—v10，保留方案和既有修改，补充缺失字段。未知新业务字段使用“默认”占位；损坏或不支持的数据结构才重建。不要把“演示重置”当作升级步骤。
- 字典关联使用稳定 ID；默认人员不占职位或编制。新增对象显示占位编码；职级按 P/M 序列格式。UI 定位与列表列宽按既有键保存。
