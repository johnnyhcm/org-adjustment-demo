## 决策与假设（讨论记录见 ../../DISSCUSION.md 六十一—八十节）

1. **选职位组件简化**：Skill 规范的 `proto-select-table-modal`（左树+中表+右已选三栏）在 M3 简化为下拉单选列表——目标职位数量少，单选已覆盖演示语义；正式接入时还原三栏弹窗。
2. **PDF 占位**：不生成实际文件，附件条目+预览点击为占位说明（PDF-01 V0.2）；AT-53/54 本轮不适用。
3. **演示控制简化**（六十九）：不做独立面板；列表页重置条 + 详情页演示操作小节。
4. **新建方案数据宇宙**为案例一基准（组织选择器从种子全量树取，演示约定）。
5. **调岗默认直接上级** = 目标组织负责人（PER-11 Demo 映射，PRD 13.2/17.1 已注明非生产规则）。
6. **方案列表参考页**（七十）：左侧四组菜单、三项筛选、查询/重置真实生效；查询方案保存/设置/删除、显示高级筛选、列配置齿轮为占位提示。
7. **列表冻结列**：不设复选框和独立序号列；方案名称+状态左冻结、操作列右冻结；操作文字全部展开，不使用“更多”。
8. **新增方案弹框**（七十一）：列表页“新增方案”打开弹框，不再跳转 02 页；范围选择为二级弹框，未确定不生效；创建成功进入工作台，取消不创建空白方案。
9. **调整范围展示**（七十二）：只保留“选择组织”按钮，不设输入框；未选择时同行显示完整子树提示，选择后同行显示已选部门并单行省略。
10. **工作台四区**（七十三）：整体固定一屏；顶部标题栏左标题/日期、右前后对比；三栏标题区 76px 等高、内容独立滚动；调整范围在组织栏；返回列表/提交在底部左右。
11. **三栏等宽与间隔**（七十四）：左中右等宽，栏间 10px；顶部标题栏/底部操作条透明底色，三栏白卡由底色分隔。
12. **工作台细节**（七十五）：组织单行、职位两行、右栏搜索、无选择时人员操作常显、选择态隐藏行内操作；拖拽 tooltip/落点色、新增绿/停用粉、把手在左复选框在右。
13. **前后对比弹框**（七十六/七十七）：前后对比/提交打开同一铺满视口的弹框，iframe 复用 04 页 embed 内容；明细单行展示全部字段；全屏架构图铺满；关闭弹框回工作台，提交成功进入详情；04 保留直达。
14. **工作台细节重做**（七十七）：胶囊统一“变更”并贴名称；标题区 76px；右栏行首占位/空态居中/hover 与选中一致；职位、人员、可用空编三区域支持全选且选择互斥。
15. 其余边界全部沿用 PRD V0.20 第 16 章 OPEN-01—13，不自行发明规则。
16. **方案分类字段**（八十二 / PRD F-01）：新增“调整层级”“调整原因”两个必填字段，调整原因选中后显示提示语；“方案说明”更名为“详细原因”（数据键仍为 `desc`）；列表、新建弹框、02 兼容页、详情与对比基本信息同步。
17. **兼职不展示**（八十一 / PRD 0.5）：开关 `FEATURES.concurrentPost=false`，隐藏右栏区块、相关文案、确认框计数与对比页签；数据层与自测断言保留。
