```bash
node tools/run-tests.js
python3 <skill-root>/scripts/check.py "原型/组织调整"
git diff --check
BASE_URL=http://127.0.0.1:8117 node tools/browser-weak-position.js
BASE_URL=http://127.0.0.1:8117 node tools/browser-compare-connectors.js
```

QA_OUTPUT_DIR 可指定截图目录；不重置用户已有浏览器方案。页面手动演示从列表选择案例或带 plan 参数进入工作台。
